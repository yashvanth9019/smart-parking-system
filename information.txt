# Project: Smart Parking Management System Using Real-Time Data

Act as a senior full-stack developer and software architect. Build a complete, advanced-level Smart Parking Management System that uses Real-Time Data (RTD) to monitor parking slot availability, manage bookings, and provide live parking updates.

## 1. Technology Stack
- Frontend: Next.js, React, HTML, CSS, Tailwind CSS
- Backend: Python FastAPI
- Database: MongoDB
- Real-time communication: WebSockets
- Charts: Chart.js
- Maps: Leaflet / OpenStreetMap
- Authentication: JWT
- Optional IoT: ESP32 with ultrasonic sensors

## 2. User Modules

- View booking history.

### Live Parking Dashboard
- Display total parking slots.
- Show available, occupied, and reserved slots.
- Update parking availability instantly without refreshing.

### Parking Booking
- Search parking locations.
- Select an available parking slot.

- QR code generation for parking entry.

- Calculate parking charges automatically.

### Real-Time Notifications
- Notify users when a slot becomes available.
- Booking confirmation notifications.
- Booking cancellation notifications.
- Parking time-expiry alerts.

## 3. Admin Module

Create a separate admin dashboard with:

## 4. Real-Time Data Processing

Implement WebSocket communication to update parking slot status instantly.

When a vehicle enters:
1. Detect vehicle presence using an IoT sensor or simulated input.
2. Send occupancy data to the backend.
3. Update MongoDB.
4. Broadcast the updated slot status using WebSockets.
5. Update the user and admin dashboards instantly.

Repeat the process when a vehicle exits.

Provide a sensor simulation mode if physical IoT hardware is unavailable.
